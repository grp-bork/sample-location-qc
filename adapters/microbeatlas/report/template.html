Likely fixes

For each flagged coordinate the audit tried the usual spreadsheet slips (swapped latitude and longitude, dropped minus signs) and kept the first one that puts the point within 25 km of the claimed country or sea, and inside the claimed state when one is named. For a land-based sample at sea the corrected point must also be on land. A slip is only proposed when the recorded point contradicts the metadata. Rows of an autofill run get the coordinate the drag started from, when that coordinate itself passes every check. — flagged samples get a likely intended position this way, including —. A correction is only listed when text backs it: the sample's own stated country or sea (a swap or sign fix must land there to be chosen at all; an autofill start must carry the same claim and pass), or a place named in the sample's location detail or the study description (table "Backed by named places"). — No position is guessed from country or region centres. These are candidates for curation, not automatic corrections.

Method and caveats

How

  • Place name: the first filled field of geo_loc_name, geographic location (country and/or sea) and eight similar fields; the part before the first colon is the claim.
  • —
  • Each distinct (coordinate, claim) pair was graded by metalog-geocoding: Natural Earth 1:10m countries and admin-1, IHO World Seas v3, Longhurst provinces, GSHHG full-resolution shorelines. The instance used here runs internally and is not publicly reachable; the code and data setup are in the repository.
  • Region check: when the claim names a state or province after the colon (USA:CA:Davis), it must lie within 25 km of the coordinate. Where Natural Earth splits a region into provinces (Italy, France, Spain, the UK), the name matches all of them.
  • Autofill: within a study, five or more coordinates in a row that step by the same amount in latitude and longitude.

Caveats

  • A region mismatch can name the lab's city rather than the field site.
  • —
  • —
  • —
  • An autofill run is missed when other coordinates of the same study sort between its members, and a one-axis run whose points all agree with their metadata is taken for a transect.

Suggested next steps

  • Hide or mark flagged coordinates in the MicrobeAtlas map views, starting with out_of_range, null_island and country_mismatch.
  • Review the diagnosed sign flips and swaps per study; most studies have one systematic slip affecting all their rows.
  • Treat the shared placeholder coordinates as missing.
  • Use the coast distance as a sample feature (e.g. coastal versus open ocean, inland versus shoreline soils).
Per-sample results (flags, diagnosis, coast distance, land/sea hierarchy) are available as TSV on request: samples.info.geo.samples.tsv, one row per sample; samples.info.geo.coords.tsv, one row per coordinate.
